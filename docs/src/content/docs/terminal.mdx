**Local terminal** starts the shell directly when only one is enabled in Settings. With several enabled, it opens a chooser. Administrator setup guidance appears only for enabled shells that support it and need Windows sudo setup. Git Bash does not need that setup.

**New terminal**, the plus and arrow button beside the tabs, opens a new tab for any saved host or installed local shell. Choosing the current host again gives you a separate SSH session.

When there are more tabs than fit, scroll them with the arrow controls or mouse wheel. **New terminal** stays visible. Hover over a tab or focus it with the keyboard to show **Rename** and **Close**.

Search, Copy, and Paste are in the tab strip. In a split group, they act on the selected pane. Search opens over the terminal and marks matches along its right edge. Each tab's status dot shows whether its session is connected, stopped, or failed.

## Splits and focus mode

Focus mode gives the terminal more room. Use its split menu for side-by-side or top-and-bottom panes. A split group can mix SSH hosts and local shells. Each group has one tab with its name and terminal count. Select it to show its panes, then use the **Panes** row or click a terminal to select where you type. Rename and delete controls sit at the end of that row. Deleting a group leaves its terminals open as regular tabs.

Drag the empty space beside **New terminal**, or elsewhere in the tab row, to move the window in Focus Mode. The space beside New terminal remains available when the tabs overflow. A thin border surrounds the selected split terminal on all four sides.

Drag the divider between terminals to change their sizes, including inside nested splits. You can also focus a divider with Tab and use the arrow keys, or hold Shift for larger steps. Double-click a divider or press Enter to reset it to equal sizes. Each group remembers its sizes across switching views and app restarts. Small windows temporarily limit pane sizes; widening the window restores your saved proportions.

Leave focus mode to return to the host's inspection views. Closing a tab with a running session asks for confirmation.

## Reconnect and copy

When an SSH session ends, use **Reconnect** in the tab strip. When a local shell exits, use **Restart**. `Ctrl+Shift+R` does the same for the active tab. After an app restart, saved tabs start fresh sessions. A failed start stays visible until you try again; the app does not retry on a timer.

Right-click copies selected text or pastes when nothing is selected. Programs that use the mouse, such as Vim or tmux, receive the click themselves. `Ctrl+Shift+C` copies and `Ctrl+Shift+V` pastes.

See [Tabs and workspaces](/control-room/workspaces/) for what returns after an app restart.
