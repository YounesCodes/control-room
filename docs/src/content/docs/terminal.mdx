Each tab holds a terminal on a saved host or a [local shell](/control-room/local-terminals/). Opening the same host twice gives you two separate sessions.

To get your tabs and split groups back after a restart, turn on **Reopen terminals from the last app session** in [Settings](/control-room/reference/settings/#terminal). It is off by default. Reopened tabs start new sessions, and old terminal output is not kept.

A tab can show the program running in it, such as `vim` or `npm`. Names you type yourself never change. Turn this off in [Settings](/control-room/reference/settings/#terminal).

## Split panes

One tab can hold several terminals side by side, and a group can mix hosts and local shells. Splits are made in focus mode, which gives the terminal the whole window.
