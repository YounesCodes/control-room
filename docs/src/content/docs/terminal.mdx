The SSH terminal uses Windows OpenSSH. Type commands as you would in any other SSH client. Local shells use the same terminal controls.

The status circle becomes a rotating ring while connecting, running a command, or opening and refreshing host inspection views. It returns to a solid circle when the work finishes. Automatic header-metric readings use the header's own status and do not spin an idle terminal's circle. With reduced motion enabled, the ring stays still. Command completion follows the shell's markers or returning prompt; a custom prompt that changes its format may need shell integration to report completion reliably. A coding agent or other program that draws its own screen and waits for you is not a running command, so its circle stays solid while it waits.

**Local terminal** starts the shell directly when only one is enabled in Settings. With several enabled, it opens a chooser. Administrator setup guidance appears only for enabled shells that support it and need Windows sudo setup. Git Bash does not need that setup.

**New terminal**, the plus and arrow button beside the tabs, opens a new tab for any saved host or installed local shell. Choosing the current host again gives you a separate SSH session.

Terminal menus stay beside their buttons and within the window. Use the arrow keys, Home, or End to move through a menu, Enter to choose, and Escape to close it. OS and shell icons reveal their identity color on hover or keyboard selection.

Tabs shrink to fit within readable limits. When there are more tabs than fit, the arrow controls and mouse wheel move through complete tabs. The down arrow beside those controls opens **All terminals**, showing full names and the selected terminal. Choose any entry to reveal its tab. **New terminal** stays visible. Hover over a tab or focus it with the keyboard to show **Rename** and **Close**.

Search, Copy, Paste, and Scratchpad are in the tab strip. In a split group, they act on the selected pane. Search opens over the terminal and marks matches along its right edge. Scratchpad opens a compact note popup for the active terminal or the shared note, and can paste the note into the terminal without running it. Each tab's status dot shows whether its session is connected, stopped, or failed.

## Splits and focus mode

Use **Focus terminal** beside the window controls at the top right. The button stays in the same position when focus mode is on; use **Exit terminal focus** to return.

Focus mode gives the terminal more room. Use its split menu for side-by-side or top-and-bottom panes. A split group can mix SSH hosts and local shells. Each group has one tab with its name and terminal count. Select it to show its panes, then use the **Panes** row or click a terminal to select where you type. Use the pencil or close button on a pane tab to rename or close that terminal. **Rename group** changes the group name. **Ungroup** asks for confirmation and leaves all its terminals open as regular tabs. Closing a pane removes only that terminal; the group remains while it has at least two panes.

Drag the thin strip along the top of the tab row to move the window in Focus Mode, even when tabs overflow. A thin border surrounds the selected split terminal on all four sides.

When a group's pane tabs overflow, **All panes** lists its terminals. Both lists show local shell logos and remote host OS icons beside their names. Use the arrow keys, Home, or End to move through either list, Enter to select, and Escape to close it.

Drag the divider between terminals to change their sizes, including inside nested splits. You can also focus a divider with Tab and use the arrow keys, or hold Shift for larger steps. Double-click a divider or press Enter to reset it to equal sizes. Each group remembers its sizes across switching views and app restarts. Small windows temporarily limit pane sizes; widening the window restores your saved proportions.

Leave focus mode to return to the host's inspection views. Closing a tab with a running session asks for confirmation.

## Reconnect and copy

When an SSH session ends, use **Reconnect** in the tab strip. When a local shell exits, use **Restart**. `Ctrl+Shift+R` does the same for the active tab. After an app restart, saved tabs start fresh sessions. A failed start stays visible until you try again; the app does not retry on a timer.

Right-click copies selected text or pastes when nothing is selected. Programs that use the mouse, such as Vim or tmux, receive the click themselves. `Ctrl+Shift+C` copies and `Ctrl+Shift+V` pastes.

See [Tabs and workspaces](/control-room/workspaces/) for what returns after an app restart.
