## Terminal

**Appearance** sets the font, text size, colors, and how many lines each terminal keeps. The preview shows your choices. **Reset colors** restores the defaults.

On Windows, **Font family** can search free monospace fonts. Select **Install and use** to install one for your account and use it right away. You don't need administrator access. On Linux, type the name of a font you already installed.

**Tabs & naming** controls whether a tab shows the program running in it, such as `vim` or `npm run dev`.

## Local terminals

Under **Local shells**, choose which shells appear in the **New terminal** menu. Hiding a shell does not uninstall it.

Turn on **Local Terminal Mode** to open your **Default local terminal** in focus mode every time Control Room starts.

## Host metrics

Turn on **Show host metrics in header** to see CPU, RAM, GPU, and disk activity for the current host in the title bar. Choose which ones to show and how often they refresh. It is off by default.

Select the readings to see charts of the last 1, 2, or 10 minutes. Charts are kept only while the app is open. Readings pause while Settings or focus mode is open, or the window is hidden.

GPU readings need performance counters on Windows, or `nvidia-smi` or an AMD driver on Linux. Mac hosts show CPU, RAM, and uptime only. A reading that isn't available shows a dash.

## Logs & History

Choose how many log lines load by default. The History switch turns command saving on or off for every host. Turning it off keeps the commands already saved. See [Command history](/control-room/tools/history/).

## Connections & Permissions

**Elevated commands** lets the host views use sudo without a password, on every host or on one host. See [Security](/control-room/reference/security/#sudo).

## App & Diagnostics

This shows the app version, update options, and the SSH setup Control Room found: which `ssh` it uses, your SSH config file, and whether ssh-agent has a key. See [Updates](/control-room/start-here/installation/#updates).
