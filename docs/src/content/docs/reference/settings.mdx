## Terminal

Choose a font, size (9–32), and scrollback limit (100–100,000 lines). You can change the text and ANSI colors for both SSH and local terminals; the cursor follows the text color. The preview shows your choices and warns if a color is hard to read. **Reset colors** restores the defaults. See [Terminal](/control-room/terminal/#reconnect-and-copy) for right-click behavior.

Use **Font family** to search open-source monospace fonts from Fontsource. Clicking the current value selects it, so you can start typing immediately.
Each suggestion shows its name in that font. Typing or using the arrow keys
updates the preview without installing anything. **Keep current font** or Escape
ends the preview and restores the current value. Choose a suggestion by clicking
it, or use the arrow keys and Enter. Choosing a suggestion does not install it.

To use an installed font or a fallback list, type it in **Font family** and choose
**Use typed font**, or press Enter without selecting a suggestion. Then use
**Save settings** to apply it. Search text is never saved automatically.

Select **Install and use** to download and install the regular font and bold
weight when available for your Windows account. The app shows download and
installation progress, then applies and saves the font for all terminals. Other
unsaved settings still need **Save settings**. Installation needs no administrator
access and the font remains installed when Control Room closes.

If the new font is not visible after installation, restart Control Room.

If a download, installation, or save fails, the current terminal font stays in
use. If Windows installed the font but saving or applying it failed, the app says so. Choose **Retry apply font** to apply it without reinstalling. Otherwise, choose **Retry install and use**. **Retry preview** and
**Retry catalog** retry their own requests. When the catalog is unavailable,
you can keep using installed fonts through **Font family**, including a list of
fallbacks such as `"JetBrains Mono", Consolas, monospace`. Cached catalog names
remain available during the current app session.

## Local terminal

Enable **Local Terminal Mode** to start **Default local terminal** in Focus Mode whenever Control Room opens. The Connections sidebar is hidden in Focus Mode. Exit focus to show it again. An existing tab for that shell is reused at startup. If the default is disabled or unavailable, the first enabled standard terminal starts. With none enabled, Local Terminal Mode opens no terminal. This mode is off by default.

Choose which installed shells appear in **Local terminal**, **New terminal**, and split menus. Hiding one does not uninstall it or close a running tab.

## Logs and History

Choose the default log length: 50, 100, 200, 500, or 1000 lines. The global History switch allows command capture on connections where you have enabled Bash integration. Turning it off stops capture and keeps saved entries. See [Command history](/control-room/tools/history/) to enable it for a host.

## Elevated reads

Allow passwordless sudo reads for all hosts, or set the allowance on one connection. This setting does not ask for or save a sudo password. See [Security](/control-room/reference/security/#elevated-reads).

## Control Room updates

See the installed version, switch automatic update checks on or off, or use **Check for updates** at any time. Updates apply to Control Room on this Windows machine. [Install and update](/control-room/start-here/installation/#updates) explains the restart.

## SSH environment

Settings shows the detected Windows OpenSSH path, your SSH config path, and whether ssh-agent has an available identity. Your OpenSSH configuration still controls SSH behavior.
