## Terminal

**Appearance** sets the font, text size, colors, and how many lines each terminal keeps.

On Windows, **Font family** can search free monospace fonts. **Install and use** installs one for your account, without administrator access. On Linux, type the name of a font you already installed.

**Tabs & naming** controls whether a tab shows the program running in it, such as `vim` or `npm run dev`, and whether **Reopen terminals from the last app session** brings back your tabs and split groups after a restart. Reopening is off by default.

## Local terminals

**Local shells** sets which shells the **New terminal** menu offers.

Turn on **Local Terminal Mode** to open your **Default local terminal** in focus mode every time Control Room starts.

## Host metrics

**Show host metrics in header** shows CPU, RAM, GPU, and disk activity for the current host in the title bar. It is off by default. You choose which readings to show and how often they refresh.

Charts cover the last 1, 2, or 10 minutes and are kept only while the app is open. Readings pause while Settings or focus mode is open, or the window is hidden.

GPU readings need performance counters on Windows, or `nvidia-smi` or an AMD driver on Linux. Mac hosts show CPU, RAM, and uptime only. A reading that isn't available shows a dash.

## Logs & History

Choose how many log lines load by default. The History switch turns command saving on or off for every host. Turning it off keeps the commands already saved. See [Command history](/control-room/tools/history/).

## Connections & Permissions

**Elevated commands** lets the host views use sudo without a password, on every host or on one host. See [Security](/control-room/reference/security/#sudo).

## App & Diagnostics

This shows the app version, update options, and the SSH setup Control Room found: which `ssh` it uses, your SSH config file, and whether ssh-agent has a key. See [Updates](/control-room/start-here/installation/#updates).
