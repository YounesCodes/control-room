---
title: Keyboard shortcuts
description: Global shortcuts for navigating the active Workspace.
---

| Shortcut       | Action                                                                          |
| -------------- | ------------------------------------------------------------------------------- |
| `Ctrl+Shift+P` | Open the command palette.                                                       |
| `Ctrl+Shift+T` | Switch the active Workspace to Terminal.                                        |
| `Ctrl+Shift+R` | Reconnect the active remote Terminal Session or restart the active local shell. |
| `Ctrl+Shift+C` | Copy the terminal's current selection.                                          |
| `Ctrl+Shift+V` | Paste the clipboard into the terminal.                                          |
| `Ctrl+Shift+W` | Close the active Workspace.                                                     |

Shortcuts act on the active Workspace. Closing a Workspace with a running session asks for confirmation.
