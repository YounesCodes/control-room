---
title: Keyboard shortcuts
description: Keys for the current tab and terminal.
---

| Shortcut       | Action                                                                              |
| -------------- | ----------------------------------------------------------------------------------- |
| `Ctrl+C`       | Copy selected terminal text. With no selection, send Ctrl+C to the running program. |
| `Ctrl+Shift+C` | Copy the terminal's current selection.                                              |
| `Ctrl+Shift+V` | Paste the clipboard into the terminal.                                              |
| `Ctrl+F`       | Search the loaded lines in Logs. `Escape` clears the search.                        |
| `Up` / `Down`  | Switch Systemd inventory units and update the inspector.                            |
| Arrow keys     | Select a nearby graph node in that direction in Systemd, Ports, and Docker.         |
| `Home` / `End` | Focus the first or last row or graph node.                                          |
| `Escape`       | Close the inspector or toolbar panel.                                               |

On macOS, replace `Ctrl` with `Cmd` for the terminal copy and paste shortcuts, so `Ctrl` combinations reach the program running in the terminal. Native `Cmd+C` and `Cmd+V` also copy and paste in the terminal. Other `Ctrl+Shift` combinations go to the program running in the terminal.

In Settings, focus the category list and use `Up` / `Down` to switch categories.
`Home` / `End` selects the first or last category. `Tab` moves into the page's
controls. In Terminal settings, `Left` / `Right` switches tabs and wraps at either
end; `Home` / `End` selects Appearance or Local shells. Arrow keys in fields keep
their normal editing behavior.
