## What you can do

- Save a host once, then open it by name.
- Open SSH and [local terminals](/control-room/local-terminals/) in tabs or side by side.
- See a host's services, ports, Docker containers, and logs. These views only read. They never change the host.

Control Room runs on Windows 11 and Ubuntu 24.04. A macOS preview is in testing.
