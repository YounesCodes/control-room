## What you can do

- Save a host once, with an optional SSH port or key path, and open it by name.
- Use SSH and [local terminals](/control-room/local-terminals/) in tabs or split panes.
- Read Linux host details, systemd units, ports, Docker containers, and logs. These views do not change the host.
- Keep several tabs open for the same host, each with its own terminal.

[Quick start](/control-room/start-here/quick-start/) shows how to install the app and open your first host.
