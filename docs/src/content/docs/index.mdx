## First time here?

<Steps>

1. **Install** the latest Windows release. The per-user installer does not require administrator access.
2. **Add connection** with a display name, SSH destination, and username.
3. **Open Workspace** by selecting the Saved Connection in the left rail.

</Steps>

See the [full Quick start](/control-room/start-here/quick-start/) for the first inspection read.
