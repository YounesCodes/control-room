---
title: About Control Room
description: What the app is for.
---

Control Room is a Windows app for connecting to Linux and Windows machines over SSH. Save a host and open a terminal. Inspect services, ports, containers, and logs where the host supports them. Windows 10 and 11 hosts let you choose an installed shell or WSL distribution before connecting.

You can also open PowerShell, Command Prompt, and Git Bash as local terminals. SSH inspection reads the connected operating system. A WSL terminal on a Windows connection still uses Windows inspection.

[Get started](/control-room/start-here/quick-start/) with your first connection.
