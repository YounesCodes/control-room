---
title: About Control Room
description: What the app is for.
---

Control Room is a Windows app for connecting to Linux machines over SSH. Save a host, open a terminal, and check its services, ports, containers, and logs in the same window. You can use it for a home server, a work machine, or a cloud VM.

You can also open PowerShell, Command Prompt, and Git Bash as local terminals. Host inspection applies to Linux SSH connections only.

[Get started](/control-room/start-here/quick-start/) with your first connection.
