---
title: About Control Room
description: What the app is for.
---

Control Room is a Windows app for connecting to Linux and Windows machines over SSH. Save a host and open a terminal. Linux hosts also offer services, ports, containers, and logs in the same window. Windows 10 and 11 hosts let you choose an installed shell or WSL distribution before connecting.

You can also open PowerShell, Command Prompt, and Git Bash as local terminals. Host inspection applies to Linux SSH connections only.

[Get started](/control-room/start-here/quick-start/) with your first connection.
