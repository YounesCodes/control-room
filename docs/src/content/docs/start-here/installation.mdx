---
title: Install and update
description: Install Control Room on Windows and keep it up to date.
---

Control Room runs on Windows 11 x64. You need the Windows OpenSSH Client for SSH connections. [Requirements](/control-room/start-here/requirements/) lists the tools needed for each host view.

1. Download the `.exe` installer from the [latest GitHub release](https://github.com/YounesCodes/control-room/releases/latest).
2. If you want to verify the download, compare it with the release's SHA-256 checksum.
3. Run the installer, then open Control Room from the Start menu.

The installer runs for your Windows user and does not need administrator access. The release is unsigned, so Windows may show an unrecognized-publisher warning.

## Updates

Control Room checks GitHub Releases while the app is open. When an update is available, use **Update available** in the title bar to see the version and changes. The download starts when you ask for it. Control Room verifies the update's signature before installation.

**Restart to update** asks for confirmation because it ends active terminals and log streams. Your saved connections and tabs remain. After the restart, the tabs open fresh terminal sessions. You can also check manually in Settings, even if automatic checks are off.
