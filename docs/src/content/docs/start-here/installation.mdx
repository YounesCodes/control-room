Control Room ships as a per-user NSIS installer for Windows 11 x64 and as a signed, notarized disk image for Apple silicon Macs running macOS 12 or later.

## Install Control Room

<Steps>

1. Open the [latest GitHub release](https://github.com/YounesCodes/control-room/releases/latest).
2. Download the package for your client and its SHA-256 checksum:
   - Windows: the x64 `.exe` installer
   - macOS: the Apple silicon `.dmg`
3. Verify the checksum if you want to check the file before opening it.
4. Run the Windows installer, or open the macOS disk image and move Control Room to Applications.

</Steps>

The Windows installer does not require administrator access.

:::caution

The current Windows package is not Authenticode-signed, so Windows may show an unrecognized-publisher warning. The macOS package is signed with a Developer ID Application certificate and notarized by Apple before the release is published.

:::

## After installation

Start Control Room from the Windows Start menu or the macOS Applications folder. The first screen opens with no Saved Connections. Select **Add connection** to create one.

See [Connections](/control-room/connections/) for all connection fields.

## Update Control Room

From v0.7.0 on, Control Room checks GitHub Releases shortly after it starts and periodically while it stays open. It also refreshes the check when you return to the app after it has been in the background long enough, so a release published while Control Room sat open is found without a restart. When a newer version exists, the titlebar shows **Update available**. Nothing appears while you are up to date.

Selecting it opens a panel with the new version and its release notes. Nothing downloads until you ask. The download runs in the background while you keep working, and the titlebar shows progress until **Restart to update** appears.

Installing always asks for confirmation, because it closes and reopens the app. Active Terminal Sessions and Log Streams end with it, and restored Workspaces come back disconnected, exactly as after any restart. After the new version starts, a dialog shows what changed once.

Update packages are signed, and Control Room verifies the signature before it installs anything. A downloaded update is held in memory and never written to local storage.

Releases before v0.7.0 were published before the updater existed, so they cannot discover or install it. Upgrading from v0.6.1 or earlier means downloading the newer installer from GitHub Releases and running it once, by hand. Every release after that can update from inside the app.
