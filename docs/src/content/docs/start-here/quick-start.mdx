You need an account on a Linux, macOS, or Windows computer that you can reach over SSH. In these docs, that computer is called the host.

1. [Install Control Room](/control-room/start-here/installation/).
2. Select **Add connection** at the bottom of the sidebar.
3. Type a name, the host's address, and your username. Leave **Port** and **Private key** empty unless your SSH setup needs them.
4. Select **Test structured access**. It checks that Control Room can sign in with an SSH key or ssh-agent, without a password prompt. The host views, such as **Systemd** and **Ports**, need that. The terminal still works with a password.
5. Select **Add connection** to save the host.

Select the host in the sidebar to open a terminal. Then pick a view under it, such as **Systemd** for services or **Ports** for open ports.

Select the question-mark icon beside Settings to open these docs from the app.
