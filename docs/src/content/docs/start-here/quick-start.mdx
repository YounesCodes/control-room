Select **Documentation**, the question-mark icon beside Settings, to open this
website in your default browser. It is also available in Focus Mode and Settings.

You need a Linux host and an SSH account for it.

1. [Install Control Room](/control-room/start-here/installation/) on Windows.
2. Select **Add connection**. Enter a name, SSH address, and username. Add a port or key file only if your SSH setup needs one.
3. Select **Test structured access** if you want to use the host inspection views. These reads need SSH access without a password prompt. A password login can still work in the terminal.
4. Save the connection and select it in the left sidebar to open a terminal.

Open **Overview** to see basic host details and current CPU and memory readings. Try **Systemd** for services or **Ports** for listeners. These views read information from the host; use the terminal when you want to run commands.

Your tabs return after an app restart and open fresh terminal sessions. If a start fails, use **Reconnect** for SSH or **Restart** for a local shell in the tab strip.

For connection fields and SSH access, see [Connections](/control-room/connections/). For tabs and splits, see [Terminal](/control-room/terminal/).
