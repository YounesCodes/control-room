A connection saves the SSH address and username for a Linux or Windows host. Select it in the sidebar to open a terminal.

Select **Add connection** in the sidebar. To change one, open its menu and choose **Edit connection**.

Enter a display name, SSH destination, and username. A port (1–65535) and identity-file path are optional. The key stays in its existing location. Control Room uses Windows OpenSSH and your normal SSH configuration.

**Test structured access** checks whether the inspection views can connect without an SSH password prompt. It does not save the connection. The terminal can still use an interactive password login if that test fails.

## Windows 10 and 11 hosts

Enable the Windows OpenSSH Server and save the host as a normal SSH connection. Shell detection needs an accepted host key and key or agent authentication that works without a prompt.

When you open a new terminal for a Windows host, Control Room checks what is installed and asks you to choose a **Remote shell** before connecting. It offers Windows PowerShell, Command Prompt, PowerShell 7 and Git Bash when found, other supported shells on the account's PATH, and each available WSL distribution. Select **Connect** to open that shell inside Control Room.

Installed Windows Terminal profiles that launch a supported shell also appear in the picker. The profile's command and arguments run over SSH. Its graphical window, colors, and other desktop settings remain in Windows Terminal.

Reconnect and restored tabs reuse their chosen shell. **New terminal** lets you choose another shell on the same host. If a selected shell was removed, open a new terminal and choose an available one.

Windows hosts offer Overview, Terminal, and Scratchpad. Linux inspection pages, Enhanced History, and remote header metrics are unavailable, including when the terminal runs WSL. WSL uses the distribution's default user and shell.

## Organize and remove hosts

Put a connection in one group and add up to five tags to help find it. Groups and tags are stored on this Windows machine; they do not change the host. Search finds names, addresses, groups, and tags.

**Delete connection** also removes its open host tabs, saved command history, and baselines. Local terminal tabs are unaffected.

If SSH or the access test fails, see [Troubleshooting](/control-room/help/troubleshooting/).
