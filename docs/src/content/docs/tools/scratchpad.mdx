Scratchpad lets you keep one plain-text note per SSH host, one note per local terminal tab, and one note shared across the app. Notes save automatically after you stop typing and remain when you close a tab. You can edit, undo, redo, or delete them.

Open **Scratchpad** beside Copy and Paste in the terminal toolbar, or search for it in the command palette. It opens beside its button in normal mode and Focus Mode. In a split group, the popup follows the selected pane.

Choose **Connection** for an SSH host's note, **Terminal** for a local tab's note, or **Global** for the shared note. **Copy** copies the note; **Paste into terminal** inserts it without running it. The compact controls provide Undo, Redo, Clear text, and Delete note. Deleting a note asks for confirmation.

Scratchpad no longer has a separate sidebar page. Previously saved Scratchpad views reopen as terminals, with their notes preserved.

Control Room never fills notes from terminal output or logs. Notes are stored locally and are not encrypted secret storage.
