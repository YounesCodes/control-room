---
title: Scratchpad
description: Write a note for a host or the whole app.
---

Scratchpad lets you keep one plain-text note per SSH host, one note per local terminal tab, and one note shared across the app. Notes save automatically after you stop typing and remain when you close a tab. You can edit, undo, redo, or delete them.

The editor fills the workspace as you resize the window. Local terminals have the same page in their navigation for their own tab's note. From a terminal, the **Scratchpad** button beside Copy and Paste opens a compact popup for the active terminal's note and the shared note, with buttons to copy the note or paste it into the terminal without running it. In a split group, the popup follows the selected pane.

Control Room never fills notes from terminal output or logs. Notes are stored locally and are not encrypted secret storage.
