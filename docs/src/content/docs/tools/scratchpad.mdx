Scratchpad lets you keep one plain-text note per SSH host, one note per local terminal tab, and one note shared across the app. Notes save automatically after you stop typing and remain when you close a tab. You can edit, undo, redo, or delete them.

Open **Scratchpad** before Copy and Paste in the terminal toolbar. It opens beside its button in normal mode and Focus Mode. In a split group, the popup follows the selected pane.

Choose **Connection** for an SSH host's note, **Terminal** for a local tab's note, or **Global** for the shared note. **Copy** copies the note; **Paste into terminal** inserts it without running it. Select part of the note and the buttons change to **Copy selection** and **Paste selection**. If the text has several lines and the shell would run each one as it arrives, the app asks first. The compact controls provide Undo, Redo, Clear text, and Delete note. Deleting a note asks for confirmation.

To copy one item from a note, right-click it or press Ctrl+C. With text selected, either copies the selection; without a selection, they copy the whole line. The note reopens with the cursor and scroll position where you left them until the app closes.

Scratchpad no longer has a separate sidebar page. Previously saved Scratchpad views reopen as terminals, with their notes preserved.

Control Room never fills notes from terminal output or logs. Notes are stored locally and are not encrypted secret storage.
