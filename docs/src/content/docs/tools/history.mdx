**Enhanced History** is optional. It records commands from new interactive Bash sessions on Linux or macOS, and zsh sessions on macOS. It does not import the account's existing `.bash_history`.

Open **History** for the host and select **Enable Enhanced History**. Control Room adds a marked block to the remote account's `~/.bashrc` and a script under `~/.local/share/control-room/`. Capture also needs **Enable Enhanced History globally** in Settings to be on.

Only sessions opened after the integration is enabled report entries. The integration reports:

- the command line
- working directory
- start and finish times
- exit code

Entries are stored on your client machine. You can search, copy, or delete them, and paste a command into the terminal without running it. **Pause** stops capture for the current tab. **Remove from remote Bash** removes the marked block and script. If several connections use the same remote account, removal affects all of them.

Command lines may contain secrets. The local database is not encrypted secret storage, so enable History only if saving those commands is appropriate. Local shells are not recorded.

**Scratchpad** is for notes you write yourself. Each connection has a note, and there is one shared note for the app. See [Scratchpad](/control-room/tools/scratchpad/) for details.

For Mac hosts, enabling history installs separate Bash and zsh scripts with marked blocks in `~/.bashrc` and `~/.zshrc`. **Remove from remote shells** removes both integrations. Existing prompt hooks remain in place. Stock macOS Bash reports times at one-second precision; zsh reports milliseconds. Fish sessions are not recorded.
