## Command history

**History** can save each command you run on a Linux or Mac host, with its folder, time, and result. It is off until you turn it on. It works in Bash, and in zsh on macOS. Commands from before you turn it on are not imported.

To turn it on:

1. Open **History** for the host and select **Enable Enhanced History**.
2. If a terminal is already open, select **Restart terminal**. This stops anything running in it. Choose **Not now** to restart later.

Turning it on adds a small marked block to `~/.bashrc` on the host, and to `~/.zshrc` on macOS. It also adds a script under `~/.local/share/control-room/`. To undo this, open **More actions** and choose **Remove from remote Bash**, or **Remove from remote shells** on macOS. This affects every connection that uses the same account on that host.

**Paste** puts a command in the terminal without running it. **Pause** stops saving for the current tab. **Clear saved history** deletes the commands saved on your computer for this host.

Commands that start with a space are skipped if Bash is set to ignore them (`HISTCONTROL=ignorespace`). Commands can contain passwords or keys, and history is saved without encryption. Turn it on only if that is acceptable. The global switch is in [Settings](/control-room/reference/settings/#logs--history).

## Scratchpad

**Scratchpad** is a plain-text note that you write yourself. Each host has one, each local terminal tab has one, and there is one **Global** note shared by the whole app. Notes save as you type.

<figure class="docs-screenshot">
  <a href={scratchpadScreenshot.src} target="_blank" rel="noreferrer">
    <img
      src={scratchpadScreenshot.src}
      alt="The Scratchpad note open beside the terminal toolbar, with Connection and Global tabs, Copy, and Paste into terminal."
    />
  </a>
</figure>

Open it with the **Scratchpad** button above the terminal. **Paste into terminal** puts the note in the terminal without running it. With nothing selected, `Ctrl+C` or a right-click copies the current line.

If the text has several lines and the shell would run each one, Control Room asks first. Notes are saved on your computer without encryption.
