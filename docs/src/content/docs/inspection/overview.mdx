Overview shows the host name, operating system, kernel, architecture, shell, and whether systemd, journald, and Docker are available. It can also show service and container counts.

Use **Refresh** to read host details again. Control Room keeps the last result locally and marks it stale after 24 hours.

Resource readings appear in the optional header instead of Overview. Enable **Show host metrics in header** in Settings, then choose CPU, RAM, GPU, disk usage, or uptime and a refresh interval. The header follows the active local or SSH workspace. Overview does not poll resource readings.
