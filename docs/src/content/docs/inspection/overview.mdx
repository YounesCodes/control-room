Overview shows the host name, operating system, kernel, uptime, shell, and whether systemd, journald, and Docker are available. It can also show service and container counts.

Use **Refresh** to read host details again. Control Room keeps the last result locally and marks it stale after 24 hours.

While Overview is visible, it reads CPU and memory from `/proc` every four seconds. **Pause** stops those reads; **Resume** starts them again. Sampling also stops when you leave or hide the view. The short graph is kept in memory only. If a reading is missing, the view says so instead of showing zero.
