---
title: Baselines
description: Save a host snapshot and compare it with a later one.
---

A baseline is a snapshot you choose to save for one SSH host. The Baselines tab arranges your saved snapshots on a timeline, so you pick a moment in time instead of picking two rows to compare.

The same **Capture baseline** button starts every capture. It opens a small dialog where you can name the capture and choose what to read:

- host identity, hardware, and timezone
- systemd units
- Docker containers
- listening ports
- firewall rules (UFW and firewalld)
- filesystems
- cron jobs
- installed packages (dpkg and rpm)

The app reads one part at a time. If you stop, completed parts stay saved and the rest are marked skipped. Each part also has a collection time and status:

| Status       | Meaning                                                   |
| ------------ | --------------------------------------------------------- |
| Collected    | The app read this part successfully.                      |
| Partial      | Some information was missing or the read reached a limit. |
| Not present  | The host does not provide this kind of information.       |
| Not readable | The read failed or the account did not have permission.   |
| Not captured | You did not select this part, or stopped before it ran.   |

The timeline shows each capture with its date, label, how much of the host it read, and how many meaningful changes happened since the capture before it. Use **Jump to latest** to reach the newest capture, and the arrow keys, Home, and End to move between them.

Selecting a capture opens two views:

- **Changes** shows the differences against another capture — the previous one by default. Every difference shows the exact before and after values.
- **State** shows everything the capture recorded, section by section.

Values that move on their own — a restarted container, a busier disk, a recreated container ID — are separated from the differences that matter. The count at the top of a comparison says how many of these routine changes were hidden, and **Show routine changes** includes them with the reason each one is routine. If a section could not be read, its changes are reported as impossible to compare instead of as unchanged, and removals from a partial read are marked unverified.

**Compare with** chooses the other side: the previous capture, the reference, any saved capture, or **Live machine (unsaved read)**, which reads the host right now without saving a baseline.

Choose a difference to open the inspector beside the workspace. It shows the recorded facts, the exact change, its classification, and **Read across captures** for that resource's values in every saved snapshot. Where the evidence is exact, it offers **Open in Systemd** or **Open in Docker** for the same unit or container.

You can rename, pin, or delete a capture, and **Mark as reference** sets one capture per host as the anchor for comparisons. A reference is protected from the 20-capture retention limit, is separate from pinning, and clearing it asks for confirmation.

Sections that need root follow the host's Allow sudo setting. If some parts could not be read, the pane can run the capture again with sudo; the earlier snapshot is never rewritten. Copy and export produce Markdown or JSON that matches what the comparison currently shows, including its warnings.
