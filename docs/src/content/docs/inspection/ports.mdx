Ports takes a snapshot of TCP and UDP listeners on the connected host. It can also show established connections, Docker port mappings, and firewall information.

Switch between **Overview**, **Connections**, **Docker**, and **Table**. Filter by protocol, address, or text. The view shows when a result was collected or cut short by a limit.

Some accounts cannot read which process owns a socket. The listener still appears, with its owner marked unavailable. **Resolve owners with sudo** can retry the read where allowed. Control Room links to a service or container only when it can match it reliably.

A listener on `0.0.0.0` accepts connections on more than one local interface, but that alone does not tell you whether it is reachable from the Internet. Firewall rules and network access are separate. Ports does not scan other machines or test reachability.
