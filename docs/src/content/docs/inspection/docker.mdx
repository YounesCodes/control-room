**Docker** shows every container on the host, including stopped ones. Containers from the same Docker Compose project are grouped together.

Select a container to see its state, health, image, ports, networks, and mounts. From there you can:

- Select a published port to open it in [Ports](/control-room/inspection/ports/).
- Select **View logs** to read its logs in [Logs](/control-room/inspection/logs/).
- Select **Open terminal** to open a shell inside a running container. Closing the tab ends the shell, not the container.

**Find containers** searches by name, image, project, or ID. **Filter containers** filters by state and changes the grouping. Drag to move around, use the wheel to zoom, and select **Fit to view** to see everything.

The view does not show environment variables or where mounts come from on the host.

## Access

The SSH account needs access to Docker on the host. On Linux, if Docker needs sudo, the view can offer a [sudo retry](/control-room/reference/security/#sudo).

- **Windows hosts.** Docker must already be running, and `docker.exe` must be installed. Docker that runs only inside WSL is not shown.
- **Mac hosts.** The view uses the SSH account's current Docker context and shows which one. A context can point to another computer. Then you see that computer's containers.
