Boot Diagnostics reads information when you open it. You can choose the current boot or one of up to ten recent boots reported by journald.

For the current boot, it can show:

- boot id and time range
- total boot time, kernel time, and userspace time
- up to 20 slow-unit observations from `systemd-analyze blame`
- current failed system-scope units
- up to 30 warning-through-alert journal entries

Boot timing, slow units, and failed-unit status are available for the current boot only. Choosing an older boot shows its journal sample and marks those other parts unavailable. Use **View journal** beside a failed unit to open its logs, or **Refresh** to read again.

The view labels missing or permission-limited information instead of treating it as an empty result. A slow unit is a clue, not proof of the cause. This information stays in memory and is not saved.
