# Control Room

> A desktop SSH client that shows what is running on your hosts.

[![Latest release](https://img.shields.io/github/v/release/YounesCodes/control-room?display_name=tag)](https://github.com/YounesCodes/control-room/releases/latest) [![CI](https://github.com/YounesCodes/control-room/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/YounesCodes/control-room/actions/workflows/ci.yml)

Save your Linux, macOS, and Windows hosts once and open a terminal on any of them. See their services, ports, Docker containers, and logs without typing commands. These views only read. They never change the host.

- Terminals in tabs and split panes, using your own OpenSSH client, keys, `~/.ssh/config`, and ssh-agent.
- Local shells too, such as PowerShell, Git Bash, and WSL on Windows, or Bash, zsh, and fish on Linux.
- In-app updates for the Windows installer and the Linux AppImage.

## Install

Download from [GitHub Releases](https://github.com/YounesCodes/control-room/releases/latest).

- **Windows 11 x64.** Run the `.exe` installer. Windows may warn that the publisher is unknown.
- **Linux.** See the [Linux install steps](https://younescodes.github.io/control-room/start-here/installation/#linux).
- **macOS.** See the [macOS preview steps](https://younescodes.github.io/control-room/start-here/installation/#macos-preview).

Or give this prompt to your agent:

```text
Install Control Room on this computer by following https://younescodes.github.io/control-room/start-here/installation/
```
